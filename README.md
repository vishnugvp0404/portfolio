# Portfolio — Vishnupriya Godaba

A simple, responsive static portfolio site built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — main page
- `styles.css` — site styles
- `script.js` — small interactive behaviors (nav, modal, theme, contact form handler)

## How to run

1. Open `index.html` in your browser. No build step required.

## Customize

- Edit `index.html` to change content: bio, projects, links, and contact info.
- Update colors and spacing in `styles.css` using CSS variables at the top.
- Hook up the contact form to a real backend or form provider (Formspree, Netlify forms, etc.) by replacing the submit handler in `script.js`.

## Accessibility & performance notes

- Keyboard accessible project cards (Enter/Space) open a modal with details.
- Theme toggle adjusts a few CSS variables for light/dark demo; you can extend it to persist choice in `localStorage`.
